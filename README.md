# Annotation

إضافة لمتصفح Chrome تتيح تظليل نصوص من صفحات الويب، وإضافة ملاحظات عليها، واستخراج الكيانات (أشخاص، مواقع، مؤسسات، تواريخ، أمراض) وتصنيفها تلقائيًا.

## مكونات المشروع

| المكوّن | الوظيفة |
| --- | --- |
| الإضافة (JavaScript + Vite) | التظليل والملاحظات وعرض بطاقات الكيانات |
| Supabase | حفظ الملاحظات والصفحات في قاعدة بيانات |
| خدمة التحليل (Python + FastAPI) | تحليل النص وإرجاع الكيانات وتصنيفاتها |

## المتطلبات

- Git
- Node.js (نسخة 18 أو أحدث)
- Python (نسخة 3.10 أو أحدث)
- متصفح Chrome

## طريقة التشغيل

### 1. نسخ المشروع

```bash
git clone https://github.com/ramaatallah/Annotation-.git
cd Annotation
```

### 2. إعداد الإضافة

```bash
npm install
```

أنشئي ملفًا جديدًا اسمه `.env.local` في نفس مكان `package.json`، وانسخي إليه الأسماء الموجودة في `.env.example`:

```
VITE_SUPABASE_URL=
VITE_SUPABASE_PUBLISHABLE_KEY=
```

**القيم الحقيقية** اطلبيها من صاحبة المشروع برسالة خاصة. لا تضعيها في الريبو أبدًا.

ثم ابني الإضافة:

```bash
npm run build
```

### 3. تحميل الإضافة في Chrome

1. افتحي `chrome://extensions`.
2. فعّلي **Developer mode** (أعلى اليمين).
3. اضغطي **Load unpacked**.
4. اختاري مجلد **`dist`**.

### 4. تشغيل خدمة التحليل (Python)

```bash
python -m venv .venv
source .venv/Scripts/activate
pip install -r requirements.txt
```

> على Mac أو Linux، أمر التفعيل هو: `source .venv/bin/activate`

ثم ادخلي إلى المجلد الذي يحتوي `main.py` و`ner.py` وشغّلي السيرفر:

```bash
cd api
uvicorn main:app --port 8000
```

انتظري حتى يظهر `Uvicorn running on http://127.0.0.1:8000`. أول تشغيل يتأخر لأن النموذج يُنزَّل من Hugging Face (يحتاج إنترنت).

للتأكد، افتحي في المتصفح: `http://127.0.0.1:8000/health`، ويجب أن يظهر `{"status":"ok"}`.

**اتركي هذا الـ terminal مفتوحًا** أثناء استخدام الإضافة.

### 5. التجربة

1. فعّلي الإضافة من أيقونتها.
2. ظلّلي نصًا في أي صفحة واكتبي ملاحظة واحفظيها.
3. ضعي الماوس على النص المظلّل، ويجب أن تظهر بطاقة الملاحظة مع بطاقات ملوّنة للكيانات.
4. حدّثي الصفحة، ويجب أن يعود التظليل.

## ملاحظات مهمة

- كل شخص يرى **ملاحظاته فقط** داخل الإضافة، لأن الإضافة تستخدم تسجيل دخول مجهول لكل متصفح. الصفوف كلها تظهر لمن عنده صلاحية على لوحة Supabase.
- بعد أي تعديل على `.env.local` أو بعد كل `git pull`: شغّلي `npm run build` ثم اضغطي زر التحديث على الإضافة في `chrome://extensions` وحدّثي الصفحة.
- إذا ظهر الخطأ `Missing Supabase configuration`، فالملف `.env.local` اسمه أو مكانه غلط، أو لم تعيدي `npm run build`.
- إذا ظهرت الرسالة "تعذّر تحليل النص"، فسيرفر Python غير شغّال. ولتشخيص السبب، افتحي `chrome://extensions` ← اضغطي **service worker** على الإضافة ← تبويب Console.

## قواعد العمل المشترك على Git

- اعملي branch خاصًا بك لكل ميزة: `git checkout -b اسمك-الميزة`، ثم Pull Request للدمج في `main`.
- قبل كل commit شغّلي `git status` وتأكدي أن `.env.local` و`.venv` ليسا في القائمة.
- لا تستخدمي `git add -f`، ولا تعدّلي `.gitignore`.
- لا تضعي مفاتيح `secret` أو `service_role` في المشروع إطلاقًا.
- أخبري المجموعة قبل أي تعديل على بنية جداول Supabase.
- إذا رفعتِ مفتاحًا بالخطأ، أبلغي صاحبة المشروع فورًا ليُغيَّر من Supabase.
