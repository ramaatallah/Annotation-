# تهيئة قاعدة بيانات Supabase (حاشية / وَهَج)

تم أرشفة الجداول والمهاجرات القديمة غير الضرورية، وتصفير قاعدة البيانات لتجهيزها للبناء الجديد النظيف.

## 📁 النسخة الاحتياطية
جميع ملفات المهاجرات السابقة محفوظة بأمان في:
`archive/supabase-backup/`

## 🧹 تصفير جداول Supabase السحابية
لحذف جميع الجداول والعلاقات القديمة من لوحة التحكم:
1. افتحي [Supabase Dashboard](https://supabase.com/dashboard).
2. اختاري مشروعك، ثم انتقلي إلى **SQL Editor**.
3. افتحي الملف `supabase/drop_all_tables.sql`، انسخي محتواه والصقيه هناك ثم اضغطي **Run**.

## 🏗️ إعادة البناء المستقبلي
عندما نحدد الجداول التي يحتاجها النظام فعلياً، سنقوم بإضافة ملف مهاجرة جديد ومنظم هنا (مثل `001_initial_clean_schema.sql`) لإنشاء الجداول بدقة دون أي جداول فائضة.
